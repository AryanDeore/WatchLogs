# Prototypes

Throwaway artifacts built to answer a design question on the [wayfinder map](https://github.com/AryanDeore/WatchLogs/issues/1).

- One subdirectory per prototype ticket, e.g. `prototypes/message-schema/`, `prototypes/menubar-layout/`.
- Each is linked from its originating issue as an asset.
- Not production code. Kept for the record of what was reacted to when a decision was made.
